# 成套文件输出规范

## 文件组织

默认建立一个案件文件夹：

```text
打印遗嘱办理材料-姓名-日期/
├── 01_打印遗嘱操作指引.docx
├── 02_打印遗嘱_个人版或夫方版.docx
├── 03_打印遗嘱_妻方版.docx（仅夫妻版）
├── 04_律师工作记录_非见证.docx
├── 05_现场签署记录.docx
├── 06_财产清单.docx
├── 07_家庭成员调查表.docx
├── 08_打印遗嘱风险告知书.docx
├── 09_见证人声明.docx
├── 10_打印遗嘱签署录像脚本.docx
├── 11_打印遗嘱证据目录.docx
└── 待补信息清单.docx（存在缺失时）
```

夫妻版由于分别立遗嘱，会比个人版多一份遗嘱文件；“十类材料”不等于固定十个文件。

## Word排版

使用A4纸；标题二号或小二黑体/小标宋居中；正文宋体小四或四号；首行缩进2字符；行距固定值22磅左右；表格适应页面；签名区留足手写空间。用户提供律所模板时从其模板。

遗嘱正文应设置“第X页/共X页”，但最终页数必须在定稿后确认。不要为压缩末页缩小到难以阅读的字号。

## 草案标记

未发生签署前，律师工作记录、现场记录、见证人声明、录像情况和签署日期均标注“草案—待实际发生后据实填写”。不得生成已经签署、已经录像、已经核验的虚假完成状态。

## 输出顺序

先完成调查表和财产清单，再生成遗嘱；遗嘱定稿后反向同步操作指引、风险告知、录像脚本和证据目录。生成Word时使用可用的专业文档能力；完成后渲染抽查标题、表格、分页、签名区、页码和空白占位符。
