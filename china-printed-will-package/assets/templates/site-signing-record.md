## 现场核对

- [ ] 核对立遗嘱人身份证原件；
- [ ] 核对两名见证人身份证原件及见证资格；
- [ ] 立遗嘱人独立表达立遗嘱目的和主要分配意愿；
- [ ] 立遗嘱人确认遗嘱全文与本人意愿一致；
- [ ] 遗嘱共【】页、一式【】份；
- [ ] 立遗嘱人和两名见证人在每一页签名；
- [ ] 每一页均注明完整年、月、日；
- [ ] 无空白页、缺页或未确认修改；
- [ ] 录像连续记录身份、表达、阅读/宣读、签署及成品展示；
- [ ] 完成原件、声明及录像的交接和保管记录。
